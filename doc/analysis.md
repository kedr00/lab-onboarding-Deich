# Отчет по коду

Я посмотрел код функции `calc_bonus`. Вот что я заметил.

## 1. Главная проблема — цикл for

В коде есть цикл `for i in range(y)`. Из-за него бонус считается не один раз, а `y` раз.

Например:
- `x = 2000`, `y = 5`, `z = 1`
- Код посчитает: 2000 * 0.15 = 300, и сделает так 5 раз.
- Итог: 1500.

Но скорее всего бонус должен считаться один раз. Тогда ответ должен быть 300.
Если `y` — это просто множитель, то цикл не нужен. Если `y` — это стаж, и бонус должен начисляться каждый год, то это странная логика, но тогда цикл нужен.

**Скорее всего, цикл здесь лишний.**
